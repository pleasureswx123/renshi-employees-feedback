# Feedback 评价平台端

本目录是员工反馈与 360° 评价业务平台的独立前端，同时承载 HR 工作台和员工工作台。

## 当前实现状态

截至2026-09-02，P1至P4已经完成并通过阶段门禁：

- 已建立 Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios 工程。
- 已接通现有 RuoYi 的登录、当前用户、退出、Token、权限和传输加密契约。
- 已建立 HR/员工双工作台、权限路由、无权限页及工作台切换。
- 已建立组件、Store、API 和真实浏览器 E2E 测试基线。
- 已建立与后端枚举和数据库检查约束一致的状态、题型、答案值、关系及结果类型常量。
- 已实现准备阶段评价项目列表、新建、编辑和删除，并接入后端权限、数据范围和乐观锁协议。
- 已实现五题型、多页、排序/跨页/复制、受限Tiptap富文本、指标与绑定；编辑、预览和后续答题复用同一题型注册表与渲染入口。
- Pinia草稿Store使用稳定业务Code关联并在保存响应后水合数据库ID；分值和权重通过四位定点数工具处理，权威发布问题由后端返回。
- P4通过9个测试文件共32项前端测试和4项Playwright浏览器测试，生产构建通过；真实后端与PostgreSQL保存、刷新恢复、键盘滑动和电脑/手机预览也已验收。

P2的13张领域表、实体和DAO位于后端。项目草稿和P4完整问卷设计器已经是真实业务链路，不再是占位页；人员关系、发布冻结、员工待办、答题、进度和报告入口仍是边界明确的未实现能力。

P4实现遵循[P4技术预检](../docs/feedback/11-p4-questionnaire-designer-precheck.md)。下一阶段为P5“人员关系、发布冻结与任务生成”，不得从当前设计器直接假定员工任务已经可用。

## 本地命令

```powershell
npm install
npm run dev
npm test
npm run build
npm run test:e2e
```

开发服务默认把 `/dev-api` 代理到 `http://127.0.0.1:9099`。如需连接其他本地后端，可通过进程环境变量 `VITE_APP_PROXY_TARGET` 覆盖代理目标。

## 开发边界

1. 阅读[平台端开发规则](./AGENTS.md)和[项目文档索引](../docs/feedback/README.md)。
2. 复用后端的账号、组织、角色和权限体系，不在本工程重复建设。
3. 不直接导入 `ruoyi-fastapi-frontend/src` 源码；所需能力在本工程按兼容契约独立实现。
4. 业务表单使用 Element Plus 表单与校验，普通业务提交使用显式点击或回车处理器。
5. 首期只允许已登录用户从系统内待办参评，不提供公开链接、二维码、小程序、邮件或短信参评入口。

后续实现顺序和退出门禁以[分阶段实施路线图](../docs/feedback/09-implementation-roadmap.md)为准。
