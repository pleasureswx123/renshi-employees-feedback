# 产品基线

## 1. 产品定位

本项目是依托 RuoYi 用户、部门、岗位、角色和权限体系建设的员工反馈与 360° 评价平台，不是通用匿名问卷平台。

平台有两个业务入口：

- HR 工作台：创建并执行评价项目。
- 员工工作台：处理评价任务和查看自己提交过的评价。

RuoYi内置超级管理员（沿用框架`user_id=1`身份）是系统维护账号，不作为被评价人或评价人。候选查询、准备期保存和发布校验统一排除该账号，旧草稿须移除后才能继续；账号管理能力及已发布历史记录保留。普通员工即使兼任HR、管理角色或与维护账号同部门，仍按原有权限和数据范围参评，不按昵称或部门名称排除人员。

首期使用场景为通过PC浏览器登录员工评价平台。手机浏览、手机作答及手机预览不在首期交付范围内。

## 2. 端到端流程

```text
HR创建评价项目
→ 编辑问卷
→ 配置指标和权重
→ 配置被评价人、评价人和评价关系
→ 发布前校验
→ 冻结项目版本并生成任务
→ 员工按被评价人逐人评价
→ HR查看回收进度
→ HR手动完成项目
→ 系统计算得分并生成基础报告
```

## 3. 员工工作台

### 3.1 我的待办

项目列表展示项目名称、开始时间、评价进度和处理入口。

```text
我的待办
→ 项目详情
→ 查看待评价人员
→ 选择一名被评价人
→ 分页答题
→ 暂存或提交
→ 提交成功
→ 继续处理其他被评价人
```

员工按被评价人逐人提交。某人的答卷提交后立即锁定，不能修改；同一项目中其他人的答卷仍可继续填写。

### 3.2 我评价的

展示当前员工已经提交过的评价项目和被评价人。提交后的答案以只读方式展示。

### 3.3 题型

首期支持：

- 单选题：选项文字、正整数选项分值（默认1分，最低1分）、批量增加选项、选择特定选项后填写原因。
- 星级打分题：最低分、最高分。
- 数字输入打分题：最低分、最高分、小数位数（新建默认0）、默认值。
- 滑动评分题：最低分、最高分、小数位数（新建默认0）、滑动步长、默认值。
- 问答题：必答和字数限制。

支持多页问卷、问卷大纲、题目排序、复制、删除、题目说明、暂存和提交。

设计器提供当前页实时预览，画布文案与参数修改即时同步，可直接试填；试填值不写入草稿或正式答案。内容未填写完整时也可预览，保存、发布仍须通过相应校验。单选题的整数限制在草稿保存与发布时执行，历史冻结配置、答案和已计算结果保留；已有数字输入、滑动评分的显式小数精度不自动修改。正式分数、权重及汇总仍采用十进制数和 PostgreSQL `NUMERIC`。

## 4. HR 工作台

### 4.1 项目列表

支持准备阶段、进行阶段和已完成状态筛选，并展示项目名称、创建时间、答卷进度和允许的操作。

### 4.2 编辑问卷

支持标题、富文本说明、多页、题型编辑、页面和题目顺序、PC实时预览及原始满分动态计算，不提供独立电脑/手机预览弹窗。

说明统一设置在问卷层级，适用于整份问卷。分页只组织页面标题、顺序和题目，不设置页面说明；题目仍可单独补充答题口径。

实时预览的页码与切页控件位于通栏分隔线上方，与大纲及编辑画布同步；正文不显示页名，每页均显示问卷标题和说明。切换页面回到问卷开头，并保留各页试填内容。

问卷原始满分是所有计分题最高可得分之和。问答题不参与数值总分。

### 4.3 指标

- 一个指标可以绑定多道题。
- 一道题首期最多属于一个指标。
- 问答题可以绑定指标，但不参与数值计算。
- 指标权重总和必须等于 100%。

### 4.4 评价关系

默认关系包括上级、同级、下级、自己、其他，并允许新增自定义关系、启停和重命名。

- “自己”由系统自动绑定本人。
- 其他关系首期由 HR 手工选择评价人。
- 一份评价任务由项目、评价人、被评价人和评价关系唯一确定。

### 4.5 发布与回收

发布前校验问卷、指标、关系、人员和权重。发布后冻结配置并生成员工待办。

HR可以查看应完成、已提交、已暂存、未开始和完成率，并按评价人、被评价人和完成状态筛选。

### 4.6 手动完成

项目只由 HR 手动完成。有未提交任务时必须展示数量并二次确认。

完成后：

- 已提交答卷保留。
- 暂存和未开始任务变为“已关闭未完成”。
- 员工不能继续填写。
- 报告只统计已提交答卷。
- 系统记录完成人、完成时间和原因。

## 5. 基础报告

首期提供：

- 回收进度。
- 团队得分排名表。
- 团队得分明细表。
- 个人指标得分表。
- 题目得分明细。
- 自评与他评对比。

首期不向被评价人开放个人报告，报告由有权限的 HR 查看。

首期报告只在系统内以网页表格交付，不提供Excel、CSV或其他文件导出。报告必须区分关系“不适用”和“已配置但未提交”，并展示完成率及实际参与计算的权重。

## 6. 保密规则

首期采用系统内保密评价，不实现真正匿名：

- 系统保存评价人身份用于任务、暂存、防重复提交和审计。
- 评价人只能查看自己的任务和答案。
- HR的进度、报告和原始答案分别授权；HR基础角色默认不能查看原始答案。
- 额外具有原始答案权限的HR只能查看已提交答案，不能查看员工草稿。
- 其他员工不能查看他人答案。


## 系统问卷模板（2026-09-07范围扩展）

创建项目可选择空白问卷或版本化系统模板。首批内置员工综合评价、管理者评价，提供预览、题目、指标权重和绑定关系；复制为独立准备阶段草稿。模板属于系统发布资源，不包含企业人员、关系权重，不自动发布。后续系统模板升级不影响已有项目。企业自建模板管理仍不在本次范围。
