# 系统问卷模板

2026-09-07按用户要求扩展原先不提供系统模板的产品边界。

- 创建对话框可选空白问卷或系统模板，并预览所有题目与指标权重。
- 员工综合评价：团队合作、沟通协调、工作效率、专业能力、积极性各20%；每个指标2道1–5分单选题，另有1道不计分的可选建议题。
- 管理者评价：目标管理、团队领导、协同决策、责任担当各25%；每个指标2道1–5分单选题，另有1道不计分的可选建议题。
- 题目是可调整的通用起点，HR应结合岗位修改。系统不替企业设定参评人员或上级/同级/下级权重，发布前仍执行原有完整校验。
- 模板随后端代码版本发布，使用稳定带版本的模板标识。模板目录接口沿用项目创建权限，不返回业务项目数据。企业模板CRUD不在本次范围。
- 创建接口新增可选templateKey，后端校验模板后通过现有草稿模型、页面/题目/指标构造及DAO复制，与项目和默认关系在同一事务中提交；失败回滚。每次生成独立代码与数据库ID，绑定关系同步重建。
- 模板来源版本保存在草稿settings.systemTemplateKey。不改变表结构，不需要数据库迁移，不影响既有项目。创建后进入原有编辑器，可独立修改、保存和发布冻结。

验证范围：模板结构与绑定、独立复制、未知模板拒绝、事务失败回滚和前端选择提交以定向测试验证；真实PostgreSQL和浏览器流程另行验证，不以单元测试替代。
